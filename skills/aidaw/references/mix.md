# 域：混音（mix）

通道参数、**发送 → 总线**、**自动化**。

| 工具 | 参数 | 说明 |
| --- | --- | --- |
| `set_gain` | `track`,`gain_db` | 轨道增益（-60..12 dB）。 |
| `set_pan` | `track`,`pan` | 声像（-1 左 .. 1 右）。 |
| `set_mute` | `track`,`on` | 静音。 |
| `set_solo` | `track`,`on` | 独奏（有任一独奏时其余自动静音）。 |
| `set_master_gain` | `gain_db` | 总输出增益。 |
| `set_sends` | `track`,`sends` | 发送列表（**整体替换**）：`[{"target":<轨道 id>,"gain_db":<dB>}]`。 |
| `set_automation` | `track`,`param`,`points` | 自动化车道（**整体替换**）：`param` 为 `gain_db`/`pan`/`cc:<0..=127>`（MIDI 控制变化），或 `inst:<参数id>`（轨道乐器）/ `fx<i>:<参数id>`（效果链第 `i` 个，`i` 从 **0** 起）；`points` 为 `[{"beat":<拍>,"value":<值>}]`，空数组 = 删除。 |

**要点**
- **总线**：新建一条空轨道当总线，把源轨的 `set_sends` 指向它；总线照常去 master，
  所以「发送」是**额外复制**一份推子后信号，不是改路由。
- 自发送（`target` = 自身）会被丢弃；指向不存在轨道的发送会被忽略。
- **自动化覆盖推子值**（读取模式）：某参数一旦有曲线，推子值对该参数不再生效。
- 自动化是「仅混音」变更：拖曲线**不会**打断音频（逐块求值）。
- **插件参数也能自动化**：`param` 除 `gain_db` / `pan` 外，还可写 `inst:<参数id>`（轨道乐器）或
  `fx<i>:<参数id>`（效果链第 `i` 个，`i` 从 0 起，如 `fx0:mix`）；参数表用 `describe_plugin` 查
  （带 `automatable` 标记）。插件参数曲线与轨道混音参数一样逐块求值并覆盖静态值；目标不存在
  （乐器/效果器被删、下标越界）时该车道不生效。
- 反馈环（互相发送）不会挂死：环上的发送被忽略。

## MIDI CC 自动化（`cc:<编号>`）

`set_automation` 的 `param` 可以直接写 `cc:<0..=127>`，值域就是 **0..127**（不是 0..1 或 dB）。
它走标准 MIDI：逐块采样曲线、只发变化值，送进该轨的**乐器**（不经过效果链），所有后端
（VST3 / CLAP / AU / 内置采样乐器）都认，不需要音源插件额外支持。

| 常用 | param | 作用 |
| --- | --- | --- |
| 调制轮 | `cc:1` | 多数音源映射到揉音 / 颤音 / 音色变化；内置采样乐器用它加调制。 |
| 呼吸 | `cc:2` | 管乐音源常用。 |
| 通道音量 | `cc:7` | 音源内部的音量（在效果链之前）。 |
| 声像 | `cc:10` | 音源内部的声像（与轨道声像不同层）。 |
| 表情 | `cc:11` | 音源内部的整体表情 / 力度缩放。 |
| 延音踏板 | `cc:64` | >= 64 = 踩下；钢琴、弦乐、采样乐器都认。 |
| 混响 / 合唱发送 | `cc:91` / `cc:93` | 音源内部的效果发送（若音源有）。 |
| 明亮度 | `cc:74` | 音源内部的滤波 / 音色亮度；**内置采样乐器忽略它**，多数外部音源可用。 |

要点：
- 与 `gain_db` / `pan` 不同，CC **不改变宿主混音**，只影响音源内部状态；轨道推子仍然照常生效。
- 逐块求值（典型 40–100 Hz，随缓冲大小），适合踏板、渐强、调制轮这类连续手势；不适合逐音精确定时。
- 相同值不会重复发送；seek / 取消静音后会重发当前值，踏板状态不会丢。
- 目标键不存在（编号越界或写错）时车道被忽略。

03开源自托管：没有 API 账单，但有 GPU 账单

05怎么选：按你的产品形态对号入座

Batch / Demo

批量草稿、短视频配歌

优先 Lyria 3.5（$0.08/首）或国内豆包 / 百炼（约 ¥0.36/首）。要中文歌、要合规，选国内云；要全球化、要英文歌，选 Lyria。

DAW / Editing

要分轨、要改段落、要转谱

Mureka 的能力最全：分轨、续写、局部编辑、转谱、混音、音色克隆都在官方 API 里。Treblo 的局部替换与流式输出更适合 C 端交互。

BGM / Licensing

纯音乐、广告、影视配乐

Stable Audio 3.0 用 $0.08 换 6 分钟纯音乐，训练数据全授权；Mubert / Soundraw 按订阅给商用授权，适合长时 BGM 与直播。

China / Compliance

国内产品、需要发票与合规

火山引擎、阿里百炼、腾讯云三选一。腾讯云直接聚合 MiniMax Music，¥1/首；火山与百炼按秒计费，约 ¥0.36/首，但要注意 AI 生成内容标识。

06接入前先确认这 6 件事

  • 输出格式与采样率：优先要求 WAV 44.1/48 kHz。ElevenLabs 主要是 MP3；腾讯云结果 URL 只有 12 小时，必须立刻转存。
  • “首”到底给几首：Mureka、Lyria 一次请求可能返回多个候选；按“可用成品”而不是“请求数”做预算。
  • 分轨与转谱是否另收费：Mureka 的下载不另收费，但分轨单独计费；Stable Audio 与 ElevenLabs 没有原生分轨。
  • 商用授权链：订阅站点的“商用”不等于 API 输出的商用；Suno 只对“付费计划内合规下载”给商用权，非官方中转拿不到。
  • 内容标识：Lyria 全量加 SynthID；Mureka 在文件尾部加音频水印；国内云需遵守生成式 AI 标识办法。
  • 失败与并发：国内云常见 QPS 2 的公共资源池；批量任务要自己做队列、重试与幂等。
